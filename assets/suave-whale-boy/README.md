## Processing

- `suave-whale-boy-idle-sizes-preview.jpg`: local QA preview at 80 px, 104 px, and 140 px.

The cleanup removes the purple background, suppresses magenta edge spill, and adds only a faint cool outline/rim for small-size readability. It does not intentionally change the face, hair, whale-fin ears, suit, shoes, or whale tail.

The plugin keeps this image as the single character identity. Idle uses restrained breathing; thinking adds an eye-level focus lens; tool use adds a pocket terminal beside the left hand; waiting adds a gold prompt ring beside the whale tail; success glints at the lapel pin and tail; and error adds a red collar alert. These cues use CSS only and contain no text.
